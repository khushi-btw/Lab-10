# Personal Tools

A simple, responsive website with three tools: a session greeting, a date and time display, and an age check.

## Run locally

With PHP 8 or newer installed, open a terminal in the project directory and run:

```sh
php -S localhost:8000
```

Open <http://localhost:8000> in your browser.

To use XAMPP, copy the project into the `htdocs` folder, start Apache, and open `http://localhost/<project-folder>/`.

## Pages

- `index.php` - Home
- `session.php`, `greeting.php`, and `logout.php` - Session greeting and sign-out
- `datetime.php` - Current date, time, and day
- `age-check.php` - Age access
